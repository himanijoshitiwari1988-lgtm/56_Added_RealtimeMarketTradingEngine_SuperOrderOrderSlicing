--- change description ---
1) Direct chart-based execution (AST) - indicator-filter mode AND strategy
   normal mode now trade directly on the evaluated chart. An option premium
   chart (CE/PE) open for the strategy trades that SAME leg/strike; a spot /
   underlying chart entry resolves a single ATM option of the signal side
   (bullish -> CE, bearish -> PE) instead of a plain underlying long. Each
   symbol's option chain collapses to ONE nearest-ATM contract per side (CE, PE)
   via firstPerSide(), so no more multi-strike fan-out entries (e.g. 2160 PE +
   2180 PE both opening). New signalSideFor() derives the leg direction from the
   strategy category or the ticked Bullish/Bearish indicator-filter direction
   (_filterBuilt synthetic strategy).

2) NSE market-hours entry gate (AST): marketSessionOpen() blocks ANY new paper
   entry while the exchange is closed (Mon-Fri IST 09:15-15:30). After 15:30 the
   candlestick feed freezes but stale candles + quotes kept satisfying entry
   conditions, so the engine kept BUY-ing dead legs after market hours and those
   phantom fills corrupted the paper PnL. Gate enforced in allowedTradesFor()
   (shared by normal poll + HFT scanner), hftScan() early-return, and a clear
   'Blocked: NSE market closed' progress message per strategy. Open positions
   are untouched (still managed to SL/TP/trail).

3) AI trail SL intent fix (AST): a typed Trail SL % on top of the Overall SL
   floor is now treated as real intent (one-time load migration) so profitable
   trades ratchet and lock profit instead of giving the whole run back to zero.
   The Overall SL %/Trail SL % UI defaults were also corrected (blank box instead
   of phantom 1%).

4) Indicator-filter strict runs (autoexperiment): 'All together (strict AND)'
   now runs pure indicator-filter strategies (one per enabled side) instead of
   ignoring the checkbox; strict results are tagged strictFilter:true and are
   kept for every backtested symbol (the drop-unprofitable pass no longer hides
   the strict outcome). autoexperiment.v13.js v130-v131; new autoexperiment.v14.js
   engine added.

5) OI Trend direction filter + OI Trend & Levels overlay: new static/oitrend.js
   (v1-v3) paints OI support/resistance from CE/PE OI walls, Max Pain, ATM-IV
   expected range, PCR and an EMA-regime trend-state line; per-strike CE vs PE OI
   fuses into trend/consolidation detection (reversal warnings when a trend
   presses a fresh/heavy wall, 'OI squeeze' consolidation, OI Bias arrows);
   premium option charts get an OI-ordered strip (CE left / PE right / spot
   centre). New OI Trend direction indicator filter added to AI Smart Trading
   and Auto Experiment (590e66d). indicators.js v50-v52.

6) SmartNTrader BB%b alert -> auto trade overhaul (v52-v58): draft-vs-armed
   config with 'Set Alert & Execute Trade' lock button, smooth-draggable overlay
   level bars with live value chip, dashed draft-preview lines, fixed overlay
   popovers (Set button never clipped), negative BB%b alert levels (-3..3), and
   NIFTY-trend-side gated CE/PE firing. Cross-and-hold (meet-style) conditions
   added to AST + AE indicator-filter key sets with checkbox UI.

7) Rate-limit + persistence (data_fetcher.py/app.py/static): per-surface quote
   cooldown (empty-bodied/429 responses no longer arm the global 30s gate),
   early return during quote cooldown, AST poll cadence 1000ms to cut Dhan load,
   reload-survival snapshots of resolved chains + picked strikes, and no strike
   dropping during Dhan rate-limit cooldown in strict runs.

8) Live UI/quote-loop fixes: AST closed-trades table repaints immediately on the
   ~250ms quote loop; PaperRun running-strategy strike rows stop blinking out on
   async re-resolve; AST open-chart draws ENTRY/SL/TP/TRAIL/live-PnL lines on the
   strike chart; FastLive ultrafast in-browser WS live candles added; NIFTY
   trend-following picks the CURRENT EMA9/21 momentum direction on a reversal and
   no longer force-exits qualifying positions that dip below the daily change%
   threshold (they stop getting new entries only).

9) One-trade-per-signal latch (AST): a strategy+instrument condition may open
   EXACTLY one trade per meeting. When the trade closes (SL/TP) while the same
   condition is still true, re-entry is blocked until the signal is observed
   FALSE and then meets again fresh. Kills the repeated same-leg re-buy churn
   (APLAPOLLO 2140 PE was bought 24x / MCX 3250 PE 8x in one losing session).
   Enforced in the normal poll and the HFT scanner (armed on placement, kept
   armed while the trade is open, released only on a false signal after the
   close, cleared each new session day).
