1) 14 new indicator definitions (static/indicators.js): Aroon, Bollinger Band
   Width, CCI, Chandelier Exit, CMF (Chaikin Money Flow), Donchian Channel,
   Elder Force Index, Fisher Transform, HMA (Hull Moving Average), Ichimoku
   Cloud, Keltner Channels, Squeeze Momentum (TTM), Stoch RSI and TSI registered
   with IndChart.IND / the chart-deploy / filter system. Each carries its own
   id/name/fullName/category/type (overlay vs pane), period inputs and compute
   engine (line/cloud/band series) so it can be deployed onto the chart AND
   referenced from the indicator-filter rows.

2) New Trend Core overlay engine (static/vlcore.js, NEW FILE): a separate
   window.VLCore trend-core engine (Trend length 31, ATR length 38, Line gap
   1.85x ATR, Confirmation bars 1, Pivot window 1, Straight line on, Volume
   confirmation on) that draws one confirmed swing-based trend line / level. It
   is loaded by index.html alongside the other static engines and feeds both the
   chart "Trend Core" overlay and the new AST/AE Trend Core filter rows.

3) Behaviour-based indicator filter rows (templates/index.html + AST aismart.js
   + AE autoexperiment.v13.js): the bullish and bearish filter panels in BOTH
   engines now generate per-indicator behaviour rows from each indicator's
   behaviour profile - Pane Indicator Behaviour groups (direction-mirror +
   strength/participation), Overlay Indicator Behaviour ("... line increasing
   upward/downward") and Meet Condition (level - "... close above/below <ind>
   (level)") rows - so a new indicator's filters appear in the UI and are wired
   into the engines' filter key sets (BULL/BEAR filter active/enabled keys,
   FILTER_EXTRA_KEYS, filter summaries and enable/disable/clear-all) without
   hand-writing each condition. Clone/copied engine tabs get the same new rows.

4) Trend Core (vlcore) filter rows in BOTH engines: the "Trend Core line
   increasing upward" / "Trend Core line increasing downward" overlay behaviour
   rows and the "Close above/below Trend Core (level)" Meet rows are injected
   into the AI Smart AND Auto Experiment bullish/bearish filter sections (exact
   labels kept). The engines compute the Trend Core level through the vlcore
   series read and hold it as a level / direction while it holds, mirroring the
   existing overlay filter rows.

5) strategies.js monitor exports: renderMonitorList + monitorTick added to the
   module exports so the monitor UI can render/tick the running-strategy list.

6) index.html cache-bust bumped (v=...) so the new indicators.js / vlcore.js
   code is served fresh to browsers.
