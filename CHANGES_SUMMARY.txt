--- change description ---
1) SMI Ergodic Oscillator (static/indicators.js, id 'smiio') compute corrected to
   match the official TradingView SMI Ergodic formula so its SMI line / Signal
   line / Histogram crossovers line up with TradingView on the same scrip,
   timeframe and settings:

   - Before: the change series was taken from the current candle's midpoint,
     pc = close - (high + low)/2, absChange = |close - (high + low)/2|. That
     non-TradingView change source made SMI/Signal behaviour (crossovers and the
     sign of the histogram vs the zero line) diverge from TradingView.
   - After: the change series is close-close momentum exactly as TradingView
     defines it -
       change = price - price[previous]
       absChange = |close - close[previous]|
     then the same double EMA chain as before (EMA(shortlen=13) then
     EMA(longlen=25) applied to both change and absChange),
       SMI = 100 * tempChange / tempAbsChange
       Signal = EMA(siglen=9) of SMI
       Histogram = SMI - Signal
     plotted unchanged (SMI / Signal lines + SMI - Signal histogram). Because
     both AST (aismart.js) and AE (autoexperiment.v13.js) read every indicator
     through IndChart.IND[id].compute(), the SMI behaviour filter rows in both
     engines (direction-mirror group rows etc.) automatically pick up the fixed
     series with no engine-side change.

2) templates/index.html cache-bust bumped (indicators.js?v=63 -> v=64) so the
   corrected indicator code is served fresh to browsers (no stale JS).

No other files changed; nothing was removed.
